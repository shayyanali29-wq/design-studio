# Rules: Accessibility (WCAG 2.2 AA baseline)

Accessibility is a P0 tier in this skill, not a section people skip.

## Contrast & color (P0)
- Text 4.5:1; large text (18px+/14px bold+) 3:1; UI components and focus indicators 3:1
- Never color alone for state: add icon + text (errors, success, required fields)
- Ghost buttons over imagery need scrim/backdrop/stroke; white-on-white anything = fail
- Audit EVERY button, input, placeholder, focus ring, helper, and error text against its actual background, both themes

## Keyboard (P0)
- Complete task flows without a mouse: nav, menus, dialogs, tabs, carousels, tables, drag alternatives
- Visible focus: `focus-visible` ring ≥ 2px with 3:1 contrast, never `outline: none` unstyled
- Logical tab order matching visual order; skip link as first focusable on content pages
- Dialogs: focus trapped, Esc closes, focus returns to trigger
- Scroll-hijack/pinned sections: arrow-key equivalent + "skip section" link; hijack must not trap focus

## Screen readers (P0/P1)
- Landmarks: header/nav/main/aside/footer; one h1, headings in order, no skipped levels used for sizing
- Images: meaningful `alt`, decorative `alt=""`; complex charts get text summaries
- Custom widgets need correct ARIA pattern (menu, tabs, dialog, combobox, switch). Prefer native elements; restyle, do not re-invent
- Live regions for async status (cart count, form success); `aria-hidden` on duplicated marquee content
- Motion-driven content changes respect reduced-motion (see motion.md)

## Touch & mobile (P0)
- Targets ≥ 44pt iOS / 48dp Android including padding; 8px spacing between adjacent targets
- Gestures have button alternatives (no swipe-only critical actions)
- Orientation: never lock unless the app genuinely requires (video, games)
- Text scaling: survive 130-200% without clipping critical actions; `rem` layouts

## Forms (P0)
- Real `<label>` bound to input; never placeholder-as-label
- Errors: text + icon, tied via `aria-describedby`, summary at top on submit failure, focus moved to summary
- Required indicated in text, not asterisk-color alone; autocomplete attributes set correctly

## Motion & vestibular (P0)
- `prefers-reduced-motion` honored above CRISP (collapse reveals, unpin stacks, stop marquees)
- Marquees/auto-updating content: pause on hover/focus + a pause control if > 5s (WCAG 2.2.2)
- No autoplaying video with sound; background video has pause control; nothing flashes > 3/s

## Language (P1)
- `lang` attribute on html + on any mixed-language spans; `dir="rtl"` handled by i18n.md
- Plain-language microcopy per copywriting.md section 6
