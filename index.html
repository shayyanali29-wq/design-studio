Design Studio

The Definitive Anti-Slop Design System for AI Agents

Create premium UIs that look hand-crafted by senior designers, not generic AI output

🎯 The Problem

AI-generated interfaces suffer from 7 critical defaults that make them look generic:

❌ Purple-Blue Gradient Glow

The #1 AI default. Every site looks the same.

❌ Centered Hero Over Dark Mesh

Every AI landing page has this pattern.

❌ Three Equal Feature Cards

The lazy "feature section" pattern.

❌ Glassmorphism on Everything

Overused blur effects without purpose.

✅ The Solution: Design Studio

47 research-backed rules with mechanical verification to create interfaces that:

  • Look unique to the brand (not generic)
  • Pass WCAG 2.2 AA accessibility standards
  • Use research-backed design patterns
  • Include proper i18n/RTL support
  • Ship with mechanical verification
  • Include real imagery (not placeholders)
  • Follow platform conventions
  • Load in <3s on 3G connections

🎨 The 5-Level Dial System

Unlike numeric 1-10 scales, Design Studio uses named levels that are easier to understand:

Level VARIANCE MOTION DENSITY
CALM Strict symmetry Static, instant states Art gallery, airy
CRISP Gentle offset Hover + fade only Roomy
BALANCED Mixed rhythm Scroll reveals, springs Standard product
BOLD Asymmetric, overlap Choreography, one hijack max Data-rich
WILD Artsy chaos Cinematic, physics Cockpit (mono numbers)

🔧 Mechanical Verification

Design Studio includes automated verification to catch issues before shipping:

# Run the linter on your files
node scripts/design-lint.mjs src/**/*.tsx src/**/*.css

# Output example:
✅ ALL CHECKS PASSED
No P0 or P1 violations found.

✅ P0 Checks (Ship Blockers)

20 automated checks including hero viewport, navigation, CTAs, accessibility, and performance.

⚠️ P1 Checks (Need Justification)

8 checks for accent colors, radius consistency, motion motivation, and copy register.
